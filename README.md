# TopDownAhoraSi
He creado la cama que hereda de BP_Interactable y cura la vida del jugador llamando a la función del jugdor Heal
Para hacer el daño he utilizado una función de Unreal para hacer daño a un jugador y el jugador lo recibe como un evento.
Cada enemigo hereda de BP_Enemy y lo único que cambia es su daño base y/o vida.
